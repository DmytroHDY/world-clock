# World Clock

Вебзастосунок для перегляду поточного часу в різних містах світу

## Мета проєкту

Мета проєкту - створити простий та зручний вебзастосунок, який дозволяє користувачу переглядати поточний час у різних містах і часових поясах

## Основні можливості

На поточному етапі реалізовано:

* відображення поточного часу
* відображення поточної дати
* вибір міста зі списку
* автоматичне оновлення часу кожної секунди
* відображення часового поясу вибраного міста
* адаптивне відображення для різних розмірів екрана

Доступні міста:

* Київ
* Лондон
* Париж
* Відень
* Нью-Йорк
* Лос-Анджелес
* Токіо
* Шанхай
* Сідней

## План розвитку

У подальшому планується додати:

1. Відображення декількох годинників одночасно
2. Додавання нових міст і часових поясів
3. Пошук міста
4. Відображення різниці в часі між містами
5. Збереження вибраних міст
6. Покращення дизайну та адаптивності
7. Інтегрування Google Maps
8. Розширення функціональності за допомогою серверної частини та бази даних
